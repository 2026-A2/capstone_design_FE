# 면접 중 나의 버릇을 분석하는 서비스

면접 연습 과정에서 사용자가 스스로 인식하지 못하는 비언어적 습관과 답변을 분석하고, 개선을 위한 피드백을 제공하는 서비스입니다.

---

## 프로젝트 소개

이 프로젝트는 온라인 면접 상황에서 사용자의 행동과 답변을 분석하여  
면접 태도 및 말버릇을 점검할 수 있도록 돕는 서비스입니다.

또한 OpenAI API를 활용하여 면접 질문을 생성하고,  
사용자가 다양한 상황에서 면접 연습을 할 수 있도록 지원합니다.

---

## 주요 기능

- 면접 질문 생성 (OpenAI API 활용)
- 면접 연습 환경 제공
- 사용자 답변 및 행동 기반 분석
- 면접 중 나타나는 습관 피드백 제공
- 개선 방향 제안

---

## Tech Stack

### Frontend
- React
- JavaScript
- Tailwind CSS

### AI (내부 기능)
- Node.js
- OpenAI API

> AI 기능은 별도 서버가 아닌, 본 레포지토리 내에서 처리됩니다.
